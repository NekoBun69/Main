# Sementes de Paz

Projeto desenvolvido para a disciplina de Desenvolvimento Front-end.

A aplicação representa uma ONG fictícia chamada Sementes de Paz, voltada para ações humanitárias, apoio à saúde e educação de crianças e famílias em situação de vulnerabilidade.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript ES6
- localStorage
- Git
- GitHub

## Funcionalidades

- Navegação em SPA
- Menu responsivo
- Formulário de cadastro
- Máscaras para CPF, telefone e CEP
- Validação de campos
- Modal de confirmação
- Persistência de dados com localStorage
- Modularização do JavaScript com import e export

## Estrutura do projeto

O projeto está organizado em arquivos HTML, CSS, imagens e módulos JavaScript separados por responsabilidade.

Principais arquivos:

- `index.html`
- `css/style.css`
- `js/script.js`
- `js/menu.js`
- `js/formulario.js`
- `js/storage.js`

## Como executar

O projeto pode ser executado localmente utilizando a extensão Live Server no Visual Studio Code.

Também pode ser publicado pelo GitHub Pages.

## Versionamento

O projeto utiliza Git e GitHub para controle de versão.

A organização das branches segue uma estrutura semelhante ao GitFlow:

- `main`: versão estável
- `Develop`: desenvolvimento
- `Feature/acessibilidade`: implementação de melhorias de acessibilidade

Também foram utilizados Issues, Pull Requests e Milestones para organizar as tarefas e alterações do projeto.

## Acessibilidade

Foram consideradas melhorias de acessibilidade como:

- textos alternativos em imagens;
- associação de labels aos campos do formulário;
- atributos ARIA;
- navegação por teclado;
- feedback visual em campos de formulário.
